# BarBew 🌈

โปรแกรมวาดแบบจำลองบาร์ (Bar Model) สำหรับการเรียนคณิตศาสตร์ระดับประถมศึกษา
ใช้งานง่าย สีสันสดใส รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

พัฒนาโดย **ครูโสภิตรา จิตชู**

## ฟีเจอร์

- ช่องพิมพ์โจทย์ ปรับขนาดตัวอักษรได้ และอัปโหลดไฟล์โจทย์ (.txt) เพื่อเลื่อนดูทีละข้อ
- เครื่องมือวาด: สร้างบาร์, เส้นตรง, เส้นประ, วงเล็บ, ปีกกา, ข้อความ (ไทย/อังกฤษ/ตัวเลข)
- กรรไกรตัดบาร์ออกเป็นสองส่วน
- คัดลอก/วาง, ลบ, ย้อนกลับ (undo), ล้างทั้งหมด
- ซูมเข้า/ออก และรองรับการบีบนิ้ว (pinch-zoom) บนอุปกรณ์สัมผัส
- เครื่องคิดเลขในตัว
- โลโก้ 3 มิติ (Three.js) มุมซ้ายบน

## เทคโนโลยี

- Vite + JavaScript (ES modules)
- HTML5 Canvas สำหรับวาด Bar Model
- Three.js สำหรับโลโก้เคลื่อนไหว 3 มิติ
- Deploy บน Vercel

## พัฒนา (Development)

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy บน Vercel

1. Push โค้ดขึ้น GitHub
2. เข้า [vercel.com](https://vercel.com) แล้วนำเข้า repository นี้
3. Vercel จะตรวจจับ Vite โดยอัตโนมัติ (build command: `npm run build`, output: `dist`)
